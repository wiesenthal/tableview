# Keyboard shortcuts

Press **⇧⌘/** in the app (or Help → Keyboard Shortcuts) to see these in a sheet.

## General

| Keys | Action |
|---|---|
| ⌘N | New connection |
| ⇧⌘F | Feedback: describe a change and get a pull request |
| ⌘, | Settings |
| ⌘K | Show or hide the Claude panel |
| ⇧⌘/ | Keyboard shortcuts |
| ⇧⌘R | Reload the window |

## Connections (welcome screen)

| Keys | Action |
|---|---|
| Type | Search saved connections |
| ↑ ↓ | Move through the list |
| ↵ | Connect (from the search box, connects to the first match) |
| ⌘⌫ | Delete the focused connection (asks first) |
| Right-click | Connect, Edit, Delete |

## Tabs

| Keys | Action |
|---|---|
| ⌘P | Open a table by name (fuzzy) |
| ⌘T | New SQL query |
| ⌘W | Close tab (pinned tabs stay; with no tab open, closes the window) |
| ⇧⌘T | Reopen the last closed tab |
| ⌘1 … ⌘9 | Go to tab 1 … 9 |
| ⇧⌘[ / ⇧⌘] | Previous / next tab |
| ⌃⇥ / ⌃⇧⇥ | Next / previous tab |
| Double-click a SQL tab | Rename it |
| Middle-click a tab | Close it |

## Table

| Keys | Action |
|---|---|
| ⌘F | Filter rows (any column contains); press again while it has focus to close it |
| ⌘R | Refresh |
| ⌘S | Review the pending SQL and commit |
| Double-click a cell | Edit it |
| Delete | Set the selected cells to NULL; with whole rows selected, mark the rows for deletion |
| ⌘C | Copy the selection |

## SQL query

| Keys | Action |
|---|---|
| ⌘↵ | Run the statement under the cursor, or the selection |
| ⇧⌘↵ | Run all statements |

## Sidebar

| Keys | Action |
|---|---|
| ↑ ↓ in the search box | Move through matching tables |
| ↵ | Open the highlighted table |
| Esc | Clear the search |
